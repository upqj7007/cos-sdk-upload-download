## 先搞清楚：COS 适合放什么

COS 适合存放图片、音视频、文档、备份包这类“文件”，尤其适合网站静态资源和用户上传内容。它是分布式存储服务，没有目录层次结构和数据格式限制，存储桶空间无容量上限，支持 HTTP/HTTPS 访问，数据会以冗余方式跨多个可用区存储。

对开发者来说更实际的一点是接入方式多：网页控制台、多种语言 SDK、API、命令行工具和图形化工具都有，还兼容 S3 的 API 接口，社区里现成的 S3 工具和插件可以直接用。

容量方面没有需要担心的上限，总数据容量和对象个数都不受限制。需要注意的是桶的数量：同一个 APPID 下最多 200 个存储桶，桶内的对象和目录数量则没有限制。

## 腾讯云对象存储怎么开通、怎么建桶

控制台操作五步能走完：注册账号、实名认证、开通 COS、创建存储桶、上传文件，全程不用写代码。

1. 注册腾讯云账号，登录控制台完成实名认证。
2. 在控制台搜索“对象存储”，进入 COS 控制台，按页面提示开通服务。
3. 左侧导航栏点“存储桶列表”，点“创建存储桶”。地域选离业务最近的，名称自己起，访问权限保持默认的“私有读写”。
4. 点进存储桶，进入“文件列表”，点“上传文件”，选好文件点上传。
5. 下载时点文件右侧的“详情”，在基本信息里点“下载对象”，或者复制临时链接到浏览器打开。

有两个建桶时就要定下来的点：地域一经指定不能更改，存储桶名称创建后也不能修改。删桶重建虽然可行，但桶里的数据要重新迁移，不如一开始就选对。官方给的地域选择参考是：离客户或数据中心近、控制成本、满足法规要求。访问权限默认私有读写是有道理的，除非你明确要让所有人访问，否则别改成公有读。

## 上传下载的五种方式，分别什么时候用

日常传文件用控制台最省事；要图形化批量管理就装 COSBrowser；要写脚本、跑批量任务用 COSCLI；要接进网站或 App，用 SDK；环境里没有现成 SDK，就走最底层的 XML API。

- **控制台**：不用写代码，适合偶尔上传下载、看文件、复制临时链接。
- **COSBrowser**：可视化客户端，上传、下载、生成访问链接都在界面里完成。
- **COSCLI**：命令行工具，用 Go 编写，Windows、macOS、Linux 都能装，支持配置多个存储桶和跨桶操作，批量上传、下载、删除可以用一条命令完成。
- **SDK**：支持 Android、C、C++、.NET(C#)、Flutter、Go、iOS、Java、JavaScript、Node.js、PHP、Python、React Native、小程序、鸿蒙等。
- **API**：XML API，直接通过 HTTP/HTTPS 发请求和接收响应，适合没有现成 SDK 的场景。

## 用 JavaScript SDK 跑通上传和下载

以 JavaScript 为例：安装 `cos-js-sdk-v5`，初始化一个 COS 实例，再调用 uploadFile 上传、getObjectUrl 获取下载地址、deleteObject 删除，三个方法覆盖最常见的文件操作。

bash
npm i cos-js-sdk-v5 --save


js
import COS from 'cos-js-sdk-v5';

const cos = new COS({
  SecretId: process.env.COS_SECRET_ID,
  SecretKey: process.env.COS_SECRET_KEY,
});


上传：

js
cos.uploadFile({
  Bucket: 'examplebucket-1250000000', // 存储桶名
  Region: 'ap-guangzhou',              // 存储桶所在地域
  Key: 'images/1.jpg',                 // 对象键，相当于文件路径
  Body: file,                          // 文件对象
  SliceSize: 1024 * 1024 * 5,          // 超过 5MB 走分块上传
  onProgress(progressData) {
    console.log(progressData);
  },
}, (err, data) => {
  if (err) {
    console.log('上传失败', err);
  } else {
    console.log('上传成功');
  }
});


SliceSize 是分块上传的阈值，超过它走分块上传，小于它走简单上传，数值可以自己调。大文件上传卡住或者超时，先看这一项。

下载不需要单独调接口取文件内容，getObjectUrl 拿到带签名的地址，再拼上 `response-content-disposition=attachment` 让浏览器强制下载：

js
cos.getObjectUrl({
  Bucket: 'examplebucket-1250000000',
  Region: 'ap-guangzhou',
  Key: 'images/1.jpg',
}, (err, data) => {
  if (err) return console.log(err);
  const url = data.Url + (data.Url.includes('?') ? '&' : '?') + 'response-content-disposition=attachment';
  window.open(url);
});


删除就是 `cos.deleteObject({ Bucket, Region, Key }, callback)`，参数和上面一样。

### 密钥别放前端，这是教程里最常见的坑

SecretId 和 SecretKey 相当于账号的钥匙。不少示例代码为了演示方便，直接把永久密钥写在前端代码里，作者自己也会注明这是图省事。本地跑跑没问题，上线不能这么干——前端代码任何人都能看到，密钥泄露等于把桶交给别人。

实际项目里的做法：创建子账号密钥，按最小权限授权，能只给某个桶的读写权限就不要给全账号权限；密钥通过环境变量读取，不要硬编码；需要在前端直传的场景，用后端签发的临时密钥，官方文档里有临时密钥生成和使用的完整指引。密钥的管理入口在“访问管理”的 API 密钥管理页面，APPID、SecretId、SecretKey 都在那里。

## 费用是怎么产生的，哪里容易花冤枉钱

费用由五部分组成：存储费用、请求费用、数据取回费用、流量费用、管理功能费用。没有固定月费，用多少算多少，买资源包可以提前锁定一部分成本。

几个能直接省钱的动作：

- 选对存储类型。全部塞进标准存储最省心，但长期不读的备份放归档或深度归档，成本结构会不一样。
- 用量稳定后再考虑资源包。有生效中的资源包会优先抵扣，没有就走按量计费，两者不需要手动切换。
- 关注免费额度。50GB 标准存储 6 个月包是开通 COS 时自动发放的，开通完去控制台确认一下到账情况。

还有一条跟数据会不会丢有关：资源包到期或用完，数据不会丢，系统自动转按量计费从余额扣；账户欠费后 COS 会在 24 小时后停止服务，数据继续保留 15 天，15 天内没续费让余额恢复到 0 以上，数据就会被销毁。

## 常见问题

**COS 能存多少数据？**
总数据容量和对象个数不受限制；同一个 APPID 下存储桶数量上限 200 个，桶内对象和目录没有数量限制。

**资源包到期了，桶里的文件会没吗？**
不会。资源包只用来抵扣费用，到期后自动转按量计费，数据不受影响；只有欠费持续 15 天才会有销毁风险。

**支持哪些开发语言？**
Android、C、C++、.NET(C#)、Flutter、Go、iOS、Java、JavaScript、Node.js、PHP、Python、React Native、小程序、鸿蒙都有 SDK。

**大文件怎么上传？**
SDK 的 uploadFile 支持分块上传，把 SliceSize 设成合适的阈值，超过阈值的文件会自动分块，小于阈值的走简单上传。

**COS 兼容 S3 吗？**
兼容 S3 的 API 接口，可以直接使用社区工具和插件。
